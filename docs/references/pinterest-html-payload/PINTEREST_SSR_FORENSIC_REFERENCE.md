# Pinterest SSR HTML & Relay Payload Forensic Reference

## Overview
This reference documentation dissects the raw HTML, Relay GraphQL payloads (`__PWS_RELAY_REGISTER_COMPLETED_REQUEST__`), Redux state (`__PWS_INITIAL_PROPS__`), and Edge Visitor Context (`__PWS_DATA__`) returned by Pinterest's unauthenticated desktop web edge for any Pin detail page (`/pin/{id}/`).

All extracted raw artifacts are preserved in this directory:
- [`raw_pin_70437491132581.html`](./raw_pin_70437491132581.html): Complete, unminified 1.2MB HTML page from Pinterest edge.
- [`relay_completed_requests.json`](./relay_completed_requests.json): Merged Relay payloads (`v3GetPinQueryv2` Initial View + Deep Closeup Query).
- [`pin_v3_full.json`](./pin_v3_full.json): Raw 122-key JSON object of `v3GetPinQueryv2.data`.
- [`pws_data_context.json`](./pws_data_context.json): Edge Anti-Bot & Fingerprinting detection parameters.
- [`initial_redux_props.json`](./initial_redux_props.json): Redux store state including Pin Builder, Marketing Plan, and Upsell metrics.
- [`social_media_posting_ld.json`](./social_media_posting_ld.json): Structured Schema.org microdata (`SocialMediaPosting`).

## 4. Edge Visitor & Anti-Bot Fingerprinting Context (`__PWS_DATA__.context`)

Pinterest edge inspects and logs the following visitor signals in every SSR response:
- `has_dcip`: Flag indicating whether request originates from a known Data Center IP (AWS, Hetzner, GCP, Cloudflare).
- `is_unauth_botspam_asn`: Flag checking if ASN is cataloged as automated scraping infrastructure.
- `is_hosting` / `is_vpn` / `is_proxy` / `is_tor`: Network proxy classification.
- `is_bot` / `social_bot`: Browser fingerprint classification.
- `analysis_ua`: Evaluated user-agent parsing and client hints compatibility.
